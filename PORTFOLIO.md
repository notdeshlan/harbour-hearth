## Project title

Café website with live opening hours, menu filters & online booking

## Your role

Designer and front-end developer

## Project description

A responsive four-page website for a Durban café (a fictional business, built as a portfolio piece).

- Live "open now" status, always in the café's time zone
- Searchable menu with vegetarian, vegan and gluten-free filters; filtered views can be shared as links
- Table booking form with time slots based on opening hours, inline validation and a confirmation screen
- Mobile-first and accessible (keyboard, screen reader and reduced-motion support)
- No framework and no image downloads, so it loads fast. TypeScript, unit-tested, auto-deployed to GitHub Pages

## Skills (pick up to 5)

Web Design · Responsive Design · TypeScript · HTML · CSS
